# Result formats

Which file format a download produces depends on the visualisation selected on the query page.

| Visualisation | Downloaded format |
|---|---|
| Table | `.csv` |
| Response | `.json` |
| Gallery | Download not supported |
| Chart | `.svg` |
| Geo | Download not supported |
| Geo-3D | Download not supported |
| Geo events | Download not supported |
| Markup | `.svg`, `.html` |
| Network | `.png` |
| Timeline | Download not supported |

The downloaded file is named after the query, with the extension of the chosen format.
