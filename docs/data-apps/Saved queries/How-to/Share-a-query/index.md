# Share a query

To share a saved query — for example in a [data story](../../stories/overview/index.md) — copy
the link used when you open the query in TriplyDB.

For a query called `timeline-cars` in the dataset `core` under the account `dbpedia`, version 9,
the link is:

```uri
https://triplydb.com/DBpedia-association/-/queries/timeline-cars/9
```

To always use the **latest** version, omit the version number:

```uri
https://triplydb.com/DBpedia-association/-/queries/timeline-cars
```

Who can open the link depends on the query's access level. A private or internal query shared
with someone who cannot see the dataset gives them nothing — see
[Access and security](../../../access-security/index.md).
