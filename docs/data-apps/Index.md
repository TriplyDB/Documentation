# TriplyDB features

Data apps are features of TriplyDB, not separate products. Each app runs inside the datacloud and works on datasets you already have, so you open it from your dataset rather than installing anything new. TriplyDB currently offers data apps like saved queries, stories, editor, flows, Knowledge Graph Builder and Knowledge graph Quality test. Each has its own chapter below, starting with an overview of what the app does and a getting started guide that takes you to your first result.
