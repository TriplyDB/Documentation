# FAQ

## Creating and editing

**Where do I create a story?**

In the stories tab in TriplyDB, using the **Create story** button.

**How do I see what my readers will see?**

Use the notepad button in the bottom-right corner to switch between the edit view and the reader
view.

**Can I put images in a story?**

Yes, in paragraph elements. Paragraph text is Markdown, so images, links and syntax-highlighted
code blocks all work.

## Query results

**Do the query results update when the data changes?**

Yes. A query element points at a saved query and the result is produced when the story is opened,
so readers see current data rather than a snapshot.

**Can I stop a story changing when someone edits the query?**

Select a version when you add the query element. Without a pinned version the element follows the
query as it changes.

**Can I write a new query without leaving the story?**

The element form offers this alongside choosing an existing query, but the documentation does not
yet describe what happens next.

## Sharing

**I shared a link and my colleague sees nothing.**

Check the access level. A story has to be public before people outside your organisation can open
it, and the same applies to an embedded story.

**How do I put a story on my own website?**

Scroll to the end of the story and click the **&lt;/&gt; Embed** button. Copy the snippet into
your HTML page. See [Share or embed a story](../How-to/share-and-embed.md).

**Can I print a story or save it as a PDF?**

There is a print option in the story menu, with a dialog and print options.

## Managing stories

**Can I move a story to an organisation?**

Yes — use **Transfer** in the story menu. **Copy** duplicates it instead of moving it.

**Can I change the banner?**

Yes, from **Change banner** in the story menu. Wide images work best.
